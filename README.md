# Wedding Invitation Web Templates

A curated collection of 5 interactive wedding invitation web templates featuring responsive layouts, audio background players, multi-language support (English, Hindi, Telugu), animations, and interactive event details.

## Templates Overview

| Directory | Theme / Description | Key Features |
| :--- | :--- | :--- |
| `template 1` | Elegant traditional wedding celebration | Parallax scrolling, multi-language switcher, RSVP cards, photo gallery, countdown timer |
| `template-2` | Modern floral watercolor invitation | Autoplay slideshow, interactive storyline, venue details, multilingual support |
| `template-3` | Premium cinematic wedding reveal | Curtained envelope intro, countdown, audio player, family introductions |
| `template-4` | Royal ornate celebration invitation | Interactive intro video reveal, event schedule timeline, multilingual translations |
| `template-5` | Contemporary luxury celebration | Video hero background, animated envelope open, custom music player, event details |

## Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/KumarADITHYA123/TEMPLATES.git
   ```
2. Navigate to any template folder:
   ```bash
   cd "template 1"
   ```
3. Open `index.html` in any modern web browser or serve via a local development server:
   ```bash
   # Python HTTP server
   python -m http.server 8000

   # Or via npx
   npx serve .
   ```

## Tech Stack
- HTML5 / CSS3 / JavaScript (Vanilla)
- Multilingual Internationalization (`i18n.js`)
- Responsive CSS Grid and Flexbox
- Web Audio API / Background MP3 integration
